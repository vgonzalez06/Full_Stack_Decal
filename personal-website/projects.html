Japan Equity Research Pipeline

A 4-stage pipeline that scrapes same-day Tokyo Stock Exchange filings (TDnet/JPX) for 8 Japanese equity positions and reads the Japanese-language PDFs natively. Claude Haiku triages what's relevant and Claude Sonnet runs the deep thesis-impact analysis, cutting API cost about 3x. The result is an automated research report with per-position confidence scores and cross-position risk synthesis.

  • Python
  • Anthropic API
  • BeautifulSoup
  • pdfminer

NFL QB Predictive Analytics Dashboard

A machine learning pipeline that predicts college QBR from features engineered out of raw college stats, like EPA per play and efficiency ratios. It compares Linear, Ridge and KNN regression, tuned with GridSearchCV and 5-fold cross-validation. An interactive Streamlit dashboard shows live predictions, feature importance and model metrics with 95% confidence intervals.

  • Python
  • Scikit-learn
  • Streamlit
  • Plotly
